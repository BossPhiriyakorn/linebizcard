# Placeholder ใน JSON แทมเพลต (ส่วนที่ใช้ได้แล้ว)

เอกสารนี้อธิบาย placeholder ที่ระบบรองรับสำหรับการ์ดใบแรก (Flex Message) — ใส่ในช่องค่าของ JSON ที่ต้องการให้ระบบแทนที่ด้วยข้อมูลจริง

---

## ข้อความ (ชื่อ, เบอร์, อีเมล, รายละเอียด)

| รายการ | ใน JSON | ตัวอย่าง | หมายเหตุ |
|--------|---------|----------|----------|
| **ชื่อ** | `"text": "{name}"` | ถูกต้อง | แทนที่ด้วยชื่อ-นามสกุลที่ผู้ใช้กรอก |
| **เบอร์โทร** | `"text": "{phone}"` | ถูกต้อง | หรือใช้ `{Tel}` ก็ได้ |
| **อีเมล** | `"text": "{email}"` | ถูกต้อง | แถวที่ label เป็น "Time" หรือ "อีเมล" ก็ใช้ค่าเดียวกันได้ |
| **รายละเอียด** | `"text": "{description}"` | ถูกต้อง | ข้อความรายละเอียดจากการ์ดใบแรก |

ใส่เฉพาะค่าใน property นั้น เช่น เปลี่ยนจาก `"text": "Brown Cafe"` เป็น `"text": "{name}"` (ไม่ต้องใส่ทั้งก้อนใหม่ แค่แก้ค่าที่ต้องการให้ระบบแทนที่)

---

## รูปภาพ

| รายการ | ใน JSON | ตัวอย่าง |
|--------|---------|----------|
| **รูปหลัก (การ์ดใบแรก)** | `"url": "{user_image}"` หรือ `"{image_url}"` | ถูกต้อง |
| **รูปการ์ดใบที่สอง (ถ้ามี)** | `"url": "{user_image2}"` หรือ `"{image_url2}"` | ถูกต้อง |

การ์ดใบแรกควรใช้ `{user_image}` หรือ `{image_url}` ในตำแหน่งที่ต้องการแสดงรูปที่ผู้ใช้อัปโหลด

---

## ปุ่มแชร์ใน LINE

| รายการ | ใน JSON | ตัวอย่าง |
|--------|---------|----------|
| **ลิงก์แชร์การ์ด** | `"uri": "{liff_url}"` | ถูกต้อง |

ใช้กับปุ่มแชร์ใน Flex Message — เมื่อกดจะเปิดการ์ดของ user ใน LINE

---

## ปุ่มโทร / ปุ่มเมล (ถ้าต้องการ)

| ปุ่ม | ใน action ของปุ่ม |
|------|-------------------|
| **โทร** | `"uri": "tel:{phone}"` |
| **อีเมล** | `"uri": "mailto:{email}"` |

---

## สิ่งที่ระบบไม่แก้

ส่วนที่**ไม่มี** placeholder (เช่น label "Time", "Tel", สี ขนาด font, layout) ระบบจะ**คงไว้ตามที่ออกแบบ** ไม่มีการแทนที่หรือเขียนทับ

---

## หมายเหตุ

- ออกแบบใน Flex Message Simulator ด้วย **URL รูปจริง** และ **ข้อความตัวอย่าง** ก่อน แล้วค่อย Copy JSON มาวางใน CMS และ**แก้ค่า**เป็น placeholder (เช่น `{name}`, `{user_image}`, `{liff_url}`) ใน JSON ด้วยมือ
- โครงสร้าง JSON ไม่ต้องมี `tectony1` ตั้งแต่แรก — ระบบจะห่อให้อัตโนมัติเมื่อบันทึก template
