# สคริปต์เช็คตาราง (ไฟล์ละ 1 ตาราง)

รันไฟล์ไหน = เห็นข้อมูลตารางนั้นเลย (คำสั่งเดียวต่อไฟล์)

| ไฟล์ | ตาราง |
|------|--------|
| `check-table-users.sql` | users |
| `check-table-memberships.sql` | memberships |
| `check-table-user-cards.sql` | user_cards |
| `check-table-templates.sql` | templates |
| `check-table-packages.sql` | packages |
| `check-table-payment-history.sql` | payment_history |
| `check-table-payment-channels.sql` | payment_channels |
| `check-table-pending-payments.sql` | pending_payments |
| `check-table-coupons.sql` | coupons |

**วิธีรัน:** เปิดไฟล์ที่ต้องการ → Execute / Run ทั้งไฟล์ (หรือกด F5) จะได้ผลลัพธ์ตารางนั้นเพียงชุดเดียว
